# Contributed skills

Optional skills beyond the built-in set. Each one is a folder with a
`SKILL.md`; the loader discovers them alongside the built-in skills.

Add your own by copying [`skills/TEMPLATE.md`](../TEMPLATE.md) to
`skills/contributed/<your-skill-name>/SKILL.md`.

Try any skill from anywhere:

```bash
python -m gogo skill install <link-to-a-SKILL.md>
```
